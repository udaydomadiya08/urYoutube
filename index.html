Credential Privacy & Transmission Boundaries

1. Strict Endpoint Isolation: Your YouTube key is sent only to https://www.googleapis.com/youtube/v3/*. Your Gemini key is sent only to https://generativelanguage.googleapis.com/*. Keys are never logged, exported in presets, or sent to third-party mirrors.
2. Server-Side .env Option: When running node server.js, you can set YOUTUBE_API_KEY and GEMINI_API_KEY in .env on the server so keys never enter browser storage.
3. Browser Storage Notice: Browser sessionStorage / localStorage is convenience storage accessible to same-origin scripts (not a hardware vault). By default, keys stay in session-only storage and clear when the tab closes.
